# Tejaswini Kadu — Portfolio

Personal portfolio: AI × Full Stack × Continuous Learning.
Plain HTML/CSS/JS, no build step.

## Run locally
Open `index.html` in a browser.

## Add your resume
Place your PDF at `resume/Tejaswini-Kadu-Resume.pdf`.

## Fill in profile stats
Edit the `PROFILE_STATS` object in `index.html` (GitHub/LeetCode numbers) and add real links for LeetCode, Codolio and Unstop when ready.

## Deploy (free)
GitHub Pages: repo Settings → Pages → Deploy from branch → `main` / root.
Or import the repo on vercel.com (framework: Other, no build command).
